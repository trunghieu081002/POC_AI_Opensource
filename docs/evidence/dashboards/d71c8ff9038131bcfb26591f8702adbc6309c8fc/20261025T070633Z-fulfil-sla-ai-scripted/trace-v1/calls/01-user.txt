# Report request
# Delivery SLA dashboard

For the operations lead. One page showing, for each order month, how many orders were eligible for the
delivery SLA, how many were delivered, how many were delivered on time, and the on-time rate. The reader must be
able to pick one or more months.

# Verified gold schema (the only tables and columns that exist)
tables:
- schema: fulfilment_sla
  table: fct_delivery_sla
  grain: one row per order month
  columns:
  - name: month
    type: text
    meaning: order month, YYYY-MM
  - name: eligible_orders
    type: bigint
    meaning: confirmed orders with a commitment date in that month
  - name: delivered_orders
    type: bigint
    meaning: eligible orders with a done outgoing transfer
  - name: on_time_orders
    type: bigint
    meaning: delivered orders whose delivery was on or before the commitment date
  - name: on_time_rate
    type: numeric
    meaning: on_time_orders / delivered_orders * 100, one decimal, per month

# KPI definitions (the only metrics a dashboard may show; use their `name`)
kpis:
- name: eligible_orders
  label: Eligible orders
  meaning: orders counted for the SLA
- name: delivered_orders
  label: Delivered orders
  meaning: eligible orders delivered
- name: on_time_orders
  label: On-time orders
  meaning: delivered on or before the commitment date
- name: on_time_rate
  label: On-time rate (%)
  meaning: the month's on-time rate; only meaningful per month

# What DPAgent can render
chart_types:
  table: 'a table: one row per combination of its `groupby` columns, one column per
    metric'
filter_types:
  select: a dropdown of the values of one column of the dashboard's dataset; it applies
    to every chart of that dataset
